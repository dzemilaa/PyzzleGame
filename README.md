# 🧩 PyzzleGame

> An interactive puzzle game with a Python/Django backend and a dynamic JavaScript frontend.

## 🚀 Live Demo
Check out the live version here: [puzzle-vi.onrender.com](https://puzzle-vi.onrender.com)

## 🛠️ Tech Stack
* **Backend:** Python, Django, SQLite
* **Frontend:** JavaScript, HTML5, CSS3

---

## ✨ Features
* Interactive puzzle-solving mechanics.
* Full-stack architecture connecting Django REST/views with a responsive web interface.
